# Интерфейс для сотрудников

Основной рабочий сценарий — настольный компьютер. При проектировании и проверке интерфейса приоритет имеют десктопные экраны, удобное расположение действий, боковые колонки и работа с таблицами.

Для телефона сохраняйте базовую доступность содержимого и основных действий. Дополнительную оптимизацию специально под мобильные устройства выполняйте по отдельному запросу или для исправления явной поломки.

Архитектура, команды проверки и особенности проекта описаны в `CLAUDE.md`.
