# Аналитика тарифов по маркам и классам техники — план (2026-09)

Статус: утверждён владельцем 2026-09-27 (все четыре предложения приняты). Продолжение
`analytics_redesign_2026_09.md`: новая вкладка «Аналитика → Тарифы» и ориентир по тарифу на карточке свода.

## 1. Цель

Понимать, сколько стоит страхование конкретной техники и **какая страховая берёт за неё меньше**:
- аналитика: тариф по классам, маркам (для спецтехники — по виду машины), по страховым внутри марки;
- работа: на карточке свода — ориентир «обычный тариф для такой техники и кто бывал дешевле», чтобы
  выбирать, кому отправлять запрос.

## 2. Что показало исследование (прод, 2026-09-27, только чтение)

- База — **все предложения страховых**, не только выигравшие: 1595 предложений 1-го года (ноябрь 2025 —
  сентябрь 2026), из них 1529 без франшизы — сопоставимы. Сделок для сравнения — всего 227.
- Поле `brand` заявки ненадёжно: парсер кладёт первое слово описания («седельный», «Гусеничный», «Комплект»);
  заполнено у 116 из 321. Марка почти всегда есть в описании объекта — черновой словарь марок узнал 79% заявок
  (КАСКО — 89%), с дополнением пропусков ожидается ≈ 95%.
- КАСКО, медиана тарифа без франшизы: Grunwald (прицепы) 1,44%, КамАЗ 1,97%, ГАЗ 2,30%, Haval 3,11%,
  BMW 3,82%, Scania 4,54% — марка (и класс за ней) влияет заметно.
- Внутри марки страховые расходятся вдвое: Haval — Зетта 1,86% … Ингосстрах 4,08%; ГАЗ — Росгосстрах 1,48% …
  Пари 3,26%; КамАЗ — Росгосстрах 1,09% … Ингосстрах 2,5%.
- Спецтехника: SANY, Zoomlion, Lovol, LiuGong, Doosan — все ≈ 0,55%: марка не решает, строим по виду машины.
- Б/у дороже нового (3,3% против 2,8%); крупные суммы дешевле в процентах (от 15 млн — 2,5%, до 3 млн — 3,0%).

## 3. Решения владельца (2026-09-27)

1. Основа сравнения — тариф 1-го года **без франшизы** (премия-1 / страховая сумма при франшизе-1 = 0);
   варианты с франшизой — отдельным переключателем.
2. Спецтехника — статистика по **виду машины** (экскаватор, кран, каток, погрузчик…), не по марке.
3. Ориентир на карточке свода — делать сразу после вкладки.
4. План — этот документ, отметки о выполнении по задачам.

## 4. Правила расчёта

- Тариф предложения = премия 1-го года / страховая сумма 1-го года × 100. Режим «без франшизы» — вариант 1 при
  франшизе-1 = 0; режим «с франшизой» — любой вариант с франшизой > 0.
- Отсекаются явные ошибки данных: тариф вне 0,05–20%.
- Показываем медиану и «обычный диапазон» (25–75-й процентили), не среднее. Минимум для вывода — 3 заявки
  (для ячейки «марка × страховая» — 2 предложения); меньше — пометка «мало данных».
- Период — по дате создания свода.
- Это описание прошлого, а не прогноз цены: регион, возраст, телематика, автозапуск тоже влияют.
