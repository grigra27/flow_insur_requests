# Страховые компании: куда уходит бизнес — метрики

Страница `summaries:analytics_insurance_companies` (`/summaries/analytics/insurance-companies/`), только для
группы «Администраторы». Код: `summaries/services/analytics_insurance_companies.py`, view и XLSX —
`summaries/views.py` (`analytics_insurance_companies`, `export_analytics_insurance_companies_widget`).
Пересобрана в рамках `docs/improvement_plans/analytics_redesign_2026_09.md` (задача 1.4).

## База

- **Сделка** — `InsuranceSummary` в статусе `completed_accepted` с непустым `selected_company`.
  Отказы клиента и своды в работе не входят (полная воронка «запросили → ответили → отказали» — этап 2 плана).
- **Период** — по дате создания свода (`summary.created_at`): быстрые 30 / 90 / 180 / 365 дней / всё время
  или явные даты (явные даты приоритетнее).
- **Фильтры** — филиал (`request.branch`) и тип страхования (`request.insurance_type`).
- Учитываются только предложения с `is_valid=True`.
- **Вариант франшизы** — `selected_franchise_variant`; если пуст — вариант 1 (попадает в «Качество данных»).

## Деньги выбранной СК в сделке

- **Страховая сумма** — `insurance_sum` предложения выбранной СК за первый (минимальный) год страхования.
  Многолетние сделки не удваиваются.
- **Премия** — сумма премий выбранного варианта франшизы по всем годам выбранной СК: это деньги, которые
  уходят в СК. Если хотя бы за один год премии нет — премия сделки не считается (см. «Качество данных»).
- **Тариф** — премия 1-го года / страховая сумма 1-го года × 100. Для СК и итогов — отношение сумм
  (взвешенный тариф), только по сделкам, где есть оба значения.

## KPI

| Показатель | Формула |
|---|---|
| Сделок | число сделок после фильтров |
| Страховая сумма | Σ страховой суммы 1-го года |
| Премия | Σ премии за все годы; подпись — средний тариф 1-го года |
| СК-победителей | число разных `selected_company`; «из N участвовавших» — СК, у которых было предложение хотя бы в одной сделке |
| Выбрана самая дешёвая | сделки, где выбранная СК — минимум цены / сопоставимые сделки |

Сопоставимость и минимум цены считает `summaries.views._build_deal_price_row` (режим: выбранный вариант
франшизы, одинаковый набор лет у сравниваемых СК, минимум две СК с ценой). Если сопоставимых сделок меньше 5 —
показывается предупреждение.

## Таблица «Куда уходит бизнес»

По каждой СК, которая участвовала хотя бы в одной сделке (сортировка: сделки ↓, участия ↓, название):

- **Сделок** и доля от всех сделок;
- **Страховая сумма**, **Премия** и их доли от итогов;
- **Тариф** 1-го года;
- **Участвовала → выиграла** — в скольких сделках у СК было предложение → сколько выиграла, доля выигрышей;
- **Самая дешёвая** — «X / Y»: в Y сопоставимых выигрышах СК X раз была самой дешёвой.

СК без выигрышей остаются внизу таблицы (сигнал: участвует, но не выбирают).

## Доли СК по месяцам

Столбцы с накоплением по месяцам создания свода: топ-6 СК по числу сделок за период + «Прочие».
Переключатель: число сделок / страховая сумма. Цвет закреплён за СК (`COMPANY_COLOR_SLOTS`), а не за местом
в рейтинге. Под графиком — таблица по месяцам (сделки, страховая сумма, лидер).

## Тепловые карты

«СК × филиал» и «СК × тип страхования» — число сделок; строки — СК-победители, колонки — филиалы по убыванию
числа сделок / типы в порядке КАСКО, спецтехника, имущество, другое. Пустой филиал/тип — «Не указан».

## Качество данных

Свёрнутый блок, число сделок и доля:

- не выбран вариант франшизы (расчёт по варианту 1);
- цены нельзя сопоставить (сделка не входит в «выбрана самая дешёвая»);
- нет страховой суммы у выбранной СК;
- нет премии выбранной СК хотя бы за один год;
- филиал не указан.

## XLSX

Одна книга с листами «Сводка», «СК», «По месяцам», «СК × филиал», «СК × тип»; в шапке каждого листа —
период и фильтры.

## Старые адреса

`/summaries/analytics/insurance-offers/` и `/summaries/statistics/` переадресуют в раздел аналитики.
Параметры, которых больше нет (`date_mode`, `comparison_mode`, `full_coverage`, `manager_online`,
`manager_alliance`, `selected_company`, `deal_status`, `widget`), игнорируются.

## Карточка страховой компании

`/summaries/analytics/insurance-companies/card/<СК>/` — открывается по ссылке из таблицы «Куда уходит
бизнес» и из «Топ-3» на обзоре; фильтры (период, филиал, тип) переносятся. Код —
`summaries/services/analytics_insurance_company_card.py`, план — этап 3
`docs/improvement_plans/analytics_redesign_2026_09.md`. База, деньги и тариф — те же, что выше.

- **Объём (3.1).** Сделки, страховая сумма, премия и тариф СК; доли — от всех сделок периода с теми же
  фильтрами. Тариф по типам страхования рядом с «рынком» — тарифом всех сделок этого типа, в какую бы СК
  они ни ушли. По месяцам — сделки СК и её доля в сделках месяца (два отдельных графика, без второй оси).
- **Что пришло (3.2).** По выигранным сделкам: филиалы; типы; вид лизинга по коду в номере ДФА
  (ЛА / ГА / ЛТ / ЛО; без кода — по типу, если он однозначен: спецтехника → ЛТ, имущество → ЛО);
  новое / б/у (`condition`, для старых заявок — `asset_status`); возраст объекта (год сделки − год выпуска:
  0–1, 2–4, 5+); страховая сумма по диапазонам (до 3 млн, 3–10, 10–30, от 30 млн); марки — только заявки
  нового формата (показано покрытие); крупнейшие лизингополучатели по страховой сумме.
- **Цена (3.3).** Сделки, где у СК было предложение. Цены сравниваются `_build_deal_price_row`: те же годы,
  вариант франшизы выбранной в сделке. «Выиграла ценой» — была самой дешёвой; «не ценой» — дороже минимума;
  «без сравнения» — меньше двух СК с ценой за те же годы. «Самая дешёвая, но проиграла» — и кому. Среднее
  место (1 — самая дешёвая) и средний отрыв от минимальной премии, %. Разрез по филиалам.
- **Воронка (3.4).** По статусам СК в сводах (`SummaryCompanyStatus`, этап 2), все своды периода:
  запрошена (= предложение + отказ + нет ответа) → предложение / отказ / нет ответа → выигрыш (свод акцептован
  с этой СК). Доля отказов по типам, филиалам, виду лизинга. Учитываются новые своды (статусы обязательны),
  восстановленные строки (`restored`) и старые своды, где сотрудник сам отмечал статусы; старый свод, у которого
  строка «предложение» появилась только автоматически, не учитывается — отказов у него нет.
- **Сделки (3.5).** Все акцептованные своды с предложением СК: итог (выиграла / кто выбран), премия СК,
  минимальная премия и отрыв, место по цене; ссылка на свод. XLSX карточки — все блоки по листам.
